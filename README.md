# 🧮 Smart Calculator

A simple, responsive, and user-friendly calculator website built with
**HTML, CSS, and JavaScript**.

The project contains multiple useful calculators along with supporting
pages such as About, Contact, Privacy Policy, Disclaimer, Terms &
Conditions, and a custom 404 page.

## ✨ Features

-   🧮 Multiple calculators in one website
-   📱 Responsive and user-friendly interface
-   ⚡ Lightweight and fast
-   🎨 Separate styling for individual calculators
-   🔢 Age Calculator
-   ⚖️ BMI Calculator
-   💰 Discount Calculator
-   🏦 EMI Calculator
-   💵 FD Calculator
-   🧾 GST Calculator
-   📊 Percentage Calculator
-   🔬 Scientific Calculator
-   📈 SIP Calculator
-   📜 Calculation history page
-   🔒 Privacy Policy page
-   📄 Terms & Conditions page
-   ⚠️ Disclaimer page
-   📞 Contact page
-   ℹ️ About page
-   ❌ Custom 404 error page
-   🤖 `robots.txt` for search-engine crawlers
-   🗺️ `sitemap.xml` for search-engine indexing
-   🚀 GitHub Pages compatible

## 🛠️ Technologies Used

-   **HTML5** --- Structure and web pages
-   **CSS3** --- Styling, layout, and responsive design
-   **JavaScript** --- Calculator logic and interactive functionality
-   **XML** --- Website sitemap
-   **TXT** --- Search-engine crawler instructions

## 🚀 Getting Started

### 1. Clone the repository

``` bash
git clone YOUR_REPOSITORY_URL
```

### 2. Open the project

Go to the project folder:

``` bash
cd Smart-Calculator
```

### 3. Run the website

Open `index.html` in a web browser.

No external framework or package installation is required.

## 🌐 Deployment

This project can be deployed as a static website using **GitHub Pages**
or any other static hosting service.

The `.nojekyll` file is included to support deployment through GitHub
Pages without Jekyll processing.
