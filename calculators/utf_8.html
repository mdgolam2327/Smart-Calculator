UTF-8 Character Chart

Explore Unicode code points and see how each character is represented as UTF-8 bytes. UTF-8 uses one to four bytes per character and is compatible with ASCII.

UTF-8 encoding patterns

Bytes Unicode code point range Bit pattern Example
1 U+0000–U+007F 0xxxxxxx A → 41

3 U+0800–U+FFFF (excluding surrogates) 1110xxxx 10xxxxxx 10xxxxxx € → E2 82 AC
4 U+10000–U+10FFFF 11110xxx 10xxxxxx 10xxxxxx 10xxxxxx 😀 → F0 9F 98 80
