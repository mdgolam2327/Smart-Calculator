Understanding Binary Numbers

What is Binary?

Binary is a base-2 number system that uses only two digits: 0 and 1.

systems use binary to represent Computers and digital electronic and process information.

Binary Place Values

Each position in a binary number represents a power of 2.

2⁵   2⁴   2³   2²   2¹   2⁰
32    16    8    4    2    1

Common Number Systems

  • Binary — Base 2
  • Octal — Base 8
  • Decimal — Base 10
  • Hexadecimal — Base 16

Where is Binary Used?

Binary numbers are used in computer systems, programming, digital electronics, networking, data storage and many other areas of computing.

❓ Frequently Asked Questions

Common questions about binary numbers and calculations.

A binary number is a number represented using only 0 and 1. It is the base-2 number system.

Each binary digit is multiplied by the corresponding power of 2. The resulting values are then added together to obtain the decimal value.

Binary arithmetic includes addition, subtraction, multiplication and division using the base-2 number system.

Bitwise operations work directly with individual binary bits. Common operations include AND, OR, XOR and NOT.

1's complement is obtained by changing every 0 to 1 and every 1 to 0.

2's complement is calculated by taking the 1's complement of a binary number and then adding 1.

Binary uses base 2, octal uses base 8, decimal uses base 10, and hexadecimal uses base 16.
