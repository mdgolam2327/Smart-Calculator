UTF-16 Character Chart

Explore Unicode code points and see their UTF-16 code units and bytes. UTF-16 stores most characters in one 16-bit code unit; characters outside the Basic Multilingual Plane use a surrogate pair.

UTF-16 encoding patterns

Unicode code point range Code unit(s) UTF-16 bytes (big-endian) Example
U+0000–U+D7FF One code unit XXXX A → 00 41
U+E000–U+FFFF One code unit XXXX € → 20 AC
U+10000–U+10FFFF High + low surrogate HHHH LLLL 😀 → D8 3D DE 00

Byte order controls how each 16-bit code unit is written; it does not change the code point or the order of the surrogate pair. A byte-order mark (BOM) is an optional stream marker, not part of a character's encoding.
